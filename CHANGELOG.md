# Change Log
All notable changes to the "filter-line" extension will be documented in this file.


## [3.0.0]
- Live sampled previews with regex, case, inverse and context controls.
- Filter unsaved/Untitled buffers and selected whole lines; direct large-file picker.
- Worker-based processing, cancellation, progress and bounded writes.
- New result files never overwrite input or previous results; preserve supported disk encodings and line endings.
- Context lines, source navigation, named presets and JSON schema validation.
- Correct target-workspace configuration, history cancellation and recency; retain legacy commands and JSON/EOML formats.
- Modern TypeScript, ESLint, unit and extension-host tests, cross-platform CI and reproducible large-file benchmark.
- Minimum VS Code version is now 1.96. Small results open as Untitled documents; implicit overwrite and placeholder-file mode are removed.
